## The idea

One site for the portfolio, the blog and the CV, in three languages, with no server and no cost.

## The tools

- **Astro** turns Markdown files into HTML pages
- **GitHub Pages** hosts the site for free
- **GitHub Actions** publishes a new version on every `git push`
